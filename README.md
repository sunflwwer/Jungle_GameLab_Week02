# 로프 스윙 3D (Rope Swing 3D)

물리 기반의 관성 제어와 공중 회전 테크닉으로 절차적 무한 맵을 돌파하는 **3D 액션 플랫포머 PC 게임**입니다. 🪢

## 🎯 프로젝트 소개

마우스 로프 매달리기와 WASD 입력 가속을 활용하여 속도감을 극대화하고, 최고 점수에 도전하는 물리 기반 3D 플랫포머 게임입니다. 물리 법칙(중력, 질량, 진자 운동)과 순수 캐릭터 움직임(Root Motion)의 상호작용만으로 정교하고 역동적인 조작감을 구현했습니다.

* **장르 / 플랫폼**: 3D 액션 플랫포머 / PC (Windows)
* **주요 모드**: 튜토리얼, 메인 스테이지(1-3), 챌린지 모드(1-3), 무한 스코어링 모드
* **핵심 루프**: 마우스 앵커 고정 ➔ WASD 스윙 타이밍 가속 ➔ 로프 해제 & 공중 회전 ➔ 최고 점수 달성

## 👩🏻‍💻 담당 역할

물리 연산 기반의 로프 스윙 메카닉과 절차적 맵 생성 시스템, 스코어링 로직을 전담했습니다.

* **물리 기반 로프 & 관성 시스템**: 마우스 레이캐스트 앵커 고정, 진자 운동 물리 연산, WASD 타이밍 가속 수식 구현
* **절차적 무한 레벨 생성**: 풀링 시스템(Object Pooling)과 청크(Chunk) 기반의 동적 지형/앵커 랜덤 배치 로직 개발
* **스코어링 & 공중 회전 시스템**: 체공 속도 및 회전 성공 여부에 따른 실시간 점수 산출 및 UI 연동

## 🎮 주요 게임 메카닉 & 시스템

* **물리 기반 로프 스윙**: 마우스 좌클릭 시 클릭 지점에 로프를 발사해 고정하며, 중력과 로프 길이에 따라 동적 진자 운동 수행
* **WASD 관성 증폭**: 스윙 최저점 타이밍에 진행 방향 키 입력 시 속도 및 스윙 폭 극대화
* **공중 회전 (Risk & Reward)**: 임계 속도 이상에서 로프 해제 시 공중 회전 트릭이 발동하여 추가 보상 점수 획득
* **무한 레벨 생성**: 플레이어 이동 동선에 맞춰 주변 앵커와 장애물 청크가 동적으로 생성되어 매번 새로운 경로 제공

## 🖥️ 사용 기술

- **Engine & Language**: Unity 3D, C#
- **VCS**: GitHub, GitHub Desktop

## 🌱 성장 경험 & 회고

* **물리 엔진 튜닝(Physics Tuning) 및 조작감 정립**: 중력, 질량, 마찰력 등의 물리 변수를 수백 차례 미세 조정하며 반응성과 무게감이 양립하는 물리 조작감을 구현했습니다.
* **오브젝트 풀링 기반 무한 레벨 파이프라인 구축**: 동적 청크 생성 방식을 통해 프레임 저하 없이 리플레이 가치가 높은 무한 맵 시스템을 안정적으로 완성했습니다.
* **위험-보상(Risk-Reward) 메카닉 연계**: 공중 회전 스코어링 시스템을 연동하여 플레이어가 자발적으로 고속 스윙을 시도하도록 동기를 유발하는 시스템 디자인을 경험했습니다.
